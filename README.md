# Return policies
Return Policy – Process Document
Purpose

To ensure that customer returns are handled consistently, efficiently and fairly, providing a positive customer experience while minimising business losses.

Process Overview

1. Customer Request
- Customer contacts the business requesting a return.
- Customer provides the order number, reason for return and relevant supporting information.
2. Eligibility Check
- If its premium customer, we always accept returns
- Customer service checks whether the purchase meets the return policy conditions.
- Verify the purchase date, return window, product condition and proof of purchase.
- Identify any exclusions (e.g. final-sale or non-returnable items).
3. Return Approval
- If eligible, approve the return and provide instructions for sending or dropping off the product.
- If not eligible, explain the reason clearly to the customer.
4. Product Inspection
- Once received, inspect the returned product.
- Confirm that its condition matches the return requirements.
- Record the inspection outcome in the system.
5. Refund or Replacement
- Process the refund using the original payment method, or arrange a replacement if requested and available.
- Notify the customer once the transaction has been completed.
6. Record Keeping
- Update the order management system with the return status.
- Record the reason for return, refund amount and final outcome.
- Use return data to identify recurring issues and opportunities for improvement.
Key Performance Indicators (KPIs)
- Return rate (% of orders returned).
- Average return processing time.
- Refund processing time.
- Percentage of returns approved.
- Customer satisfaction following a return.
Expected Outcome

A standardised return process that improves customer satisfaction, ensures policy compliance and provides useful insights into product quality and operational performance.
